## Спринт 6 Сервер и азбука Морзе

### Задание

Реализовать сервер, который будет конвертировать текст в азбуку Морзе и наоборот.

### Решение

1. Реализовать сервер, который будет конвертировать текст в азбуку Морзе и наоборот.
2. Реализовать клиент, который будет отправлять запросы на сервер.
3. Реализовать функцию распознавания текста - Морзе или нормал.
4. Реализовать логирование.
